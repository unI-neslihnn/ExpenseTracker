<h1>💰 Expense Tracker</h1>

Expense Tracker, kullanıcıların kişisel gelir ve giderlerini yönetmesini, harcamalarını grafiklerle analiz etmesini, canlı döviz kurlarını takip etmesini ve verilerini internet olmadan cihazda saklamasını sağlayan React Native ve Expo tabanlı bir mobil bütçe takip uygulamasıdır.

<h3>📌 Özellikler</h3>

Gelir ve Gider Takibi: Kategori, tutar ve para birimi seçerek hızlı işlem kaydetme.
Kategori Grafikleri: Harcamaları kategorilere göre pasta grafik ile görselleştirme.
Offline Çalışma: Tüm verileri yerel SQLite veritabanında güvenle saklama.
Canlı Döviz Kurları: Anlık Dolar ve Euro kurlarını çekme ve önbellekte tutma.
Arama ve Filtreleme: İşlemler arasında anlık arama yapma ve tür filtreleme.
JSON Yedekleme: Tüm verileri tek dokunuşla dosya olarak dışa aktarma ve paylaşma.
Özel Tasarım: Navy, Warm Beige ve Soft Gold tonlarında şık ve sade arayüz.

<h3>🚀 Kurulum ve Çalıştırma</h3>

1. Repoyu klonlayın:
git clone https://github.com/KULLANICI_ADINIZ/ExpenseTracker.git
cd ExpenseTracker

2. Paketleri yükleyin:
npm install

3. Uygulamayı başlatın:
npx expo start -c

Telefonunuzdaki Expo Go uygulaması ile QR kodu okutarak test edebilirsiniz.
